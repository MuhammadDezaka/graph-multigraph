Materi Detail Graph

1. Konsep Dasar Graph

▼

Graph adalah struktur data non-linear yang terdiri dari:

  • Vertex (Simpul): Titik yang merepresentasikan objek
  • Edge (Sisi): Garis yang menghubungkan antar vertex

Contoh penerapan graph dalam kehidupan sehari-hari:

  • Jaringan sosial media
  • Peta dan navigasi
  • Jaringan komputer

2. Jenis-jenis Graph

▼

2.1 Berdasarkan Arah:

  • Graph Berarah (Directed Graph): Sisi memiliki arah tertentu
  • Graph Tak Berarah (Undirected Graph): Sisi tidak memiliki arah

2.2 Berdasarkan Bobot:

  • Graph Berbobot: Setiap sisi memiliki nilai/bobot
  • Graph Tidak Berbobot: Sisi tidak memiliki nilai khusus

3. Representasi Graph

▼

3.1 Matriks Ketetanggaan (Adjacency Matrix):

Matriks berukuran n x n dimana n adalah jumlah vertex. Nilai 1 menunjukkan ada sisi, 0 tidak ada sisi.

3.2 Senarai Ketetanggaan (Adjacency List):

Daftar vertex yang bertetangga untuk setiap vertex dalam graph.
